# Egg Product Image Upload Add-on

This overlay adds optional product photo uploads to the existing Laravel egg inventory system.

Features:
- Admin can upload a photo when creating an egg product.
- Admin can replace or remove a photo from the Edit Product page.
- Product thumbnails appear in the admin catalogue.
- Uploaded photos appear on the customer home product cards and Order Eggs page.
- Products without an uploaded photo show a clear fallback placeholder.
- Accepted image types: JPG, JPEG, PNG, WEBP. Maximum file size: 4 MB.
- Existing inventory, order, authentication, and role logic is otherwise left alone.
